Project story

The live Automation Lab map

I wanted another way to understand what the lab is doing: start with the whole estate, select a platform, and keep drilling until the map reaches the workload, service, container, VM, pipeline, or certificate that explains the current state.

Open the live map

The graph is built from operating data

The map is not a second hand-maintained diagram. It assembles its hierarchy from the same Prometheus, Zabbix, Jenkins, Kubernetes, certificate, backup, mail, and AI operations signals used by the monitoring stack. A parent inherits the worst state below it, but every alert remains traceable by selecting the affected branch.

The result is several layers deep. Kubernetes continues through namespaces, controllers, replica sets, pods, containers, services, ingress, and storage. Infrastructure continues from the Proxmox hypervisors to their VMs and resource detail. Delivery pipelines split into operational groups before reaching individual jobs.

Health is separate from identity

Icons describe what a node is. The ring, status mark, and legend describe its health. That keeps a healthy Kubernetes node from looking critical just because the same symbol is reused, and it lets vendor marks coexist with generic symbols for systems that do not have one.

The detail strip holds scale, runtime, resources, and network context. Long resource values wrap instead of ending in an ellipsis, so CPU and memory remain readable on hypervisors and VMs.

The public copy only has an outbound path

The private map creates a separate public projection with opaque IDs and sanitized details. A publisher validates that projection and writes it outward to a Worker-owned durable key-value store. The public page reads from the Worker. There is no route from the public site back into the lab.

If the feed stops, the Worker reports it as stale instead of serving old data as live. The browser can then keep the last successful graph it received and labels it with the stored timestamp. The page remains useful without turning missing telemetry into a green state.
