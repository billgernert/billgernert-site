Project story

AIOps morning triage

The daily triage chain collects overnight signal from monitoring, CI, and backups, correlates it deterministically, and uses a model only where the model earns its place. The output is a digest and a finding row, never a command.

Collect first so a quiet night is distinguishable from a broken collector

Each run starts by sweeping the systems that already know something happened: monitoring, metrics, CI, and backup results. The collectors leave a heartbeat of their own because "nothing failed" and "the collector never ran" are different states, and a quiet digest is only useful if it can prove it was quiet on purpose.

The correlation step is done in code rather than asked of the model. That keeps the relationships repeatable and leaves the model to the part it is actually good at, which is classifying and summarizing the result once the facts are already in one place.

Local first, paid only for the hard cases

The common path is a local model. It handles the cheap, high-volume classification work with no per-call cost and no need to move the easy cases off the platform. A paid model is there for the cases the local path cannot handle with confidence, and it sits behind the same budget gate and hard cap as the rest of the AI stack.

That matters because the value here is in the boundary, not in the word "AI." The hard cases can escalate. The easy cases do not quietly consume budget just because a model was available.

The output stays advisory by design

Scanner triage can only ever downgrade a finding on a valid noise verdict. If the model is down, times out, or answers with nonsense, the finding stays real. Untrusted text is fenced and treated as data, and there is no path from model output to execution. The result becomes a row, an email, or an issue, not a shell command.

That is why the digest is useful. It explains what looked wrong and what to check first without pretending the model gets to apply the fix.

Live AIOps and alerting evidence

This public-safe dashboard shows the gateway budget, service health, component capacity, the latest triage result, triage activity, and aggregate alert severity. Findings, prompts, model responses, host identities, and internal management links stay private.
