How it is built: generated, not asserted

Every item of work carries a ratified milestone and a status. A generator rolls those up by milestone and writes the snapshot below - the same discipline the rest of the site uses, where a status view is a pure function of the tracked source, never a hand edit. So the roadmap cannot drift from reality: closing a piece of work is what advances it here, on the next regeneration.

What the states mean

  • Designed - the work is specified and filed, not yet started.
  • Building - it is in progress: code or config committed, moving toward done.
  • Done - the deliverable is committed and verified; anything that can only be confirmed on live infrastructure is confirmed by an operator before it is called done.
