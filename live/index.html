What crosses the public boundary

The public views preserve enough context to explain the system without publishing its private wiring.

  • The Platform map keeps reviewed functional names and drill-down relationships. It removes internal identifiers, addresses, domain suffixes, raw alerts, exact capacity, and administration links.
  • The architecture diagram shows operating shape and points to the pages that explain each region.
  • The NOC publishes curated measurements and makes missing data explicit.
  • A designed but undeployed subsystem stays labeled as designed. It does not become running evidence.
